# CLPS Lunar Mission Browser — Static Demo

This folder is a static frontend prototype for the Site06 dashboard concept. It is not the scientific Streamlit application and does not fetch live NASA data or calculate visibility. Any values embedded in the page are unverified interface fixtures, not analysis results.

## View locally

Open `index.html` directly in a browser, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`. The CSS, JavaScript, map, and saved representative sample rows are local files; the page does not call an API or request external assets.

## Deploy to Netlify

Use `netlify-demo` as the site base/publish directory, or drag and drop this folder into Netlify's static deploy flow. The included `netlify.toml` publishes the folder contents.

## Demo data note

The page contains embedded example values for layout review only. They are not generated by the demo controls and are not verified analysis results. Those controls do not run SPICE or recompute geometry, terrain horizons, visibility, or mission windows. The interactive Streamlit application is required for scientific calculations.
